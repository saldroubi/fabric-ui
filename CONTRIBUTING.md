# Contributing

This is a personal project, but PRs and issues are welcome.

Before opening a PR:

```sh
npm run lint
npm run check
npm run build
```

All three run in CI on every PR, so it's faster to catch issues locally first.

For anything nontrivial (new features, larger refactors), consider opening an issue first to
discuss the approach before investing time in an implementation — it may not fit the project's
direction (see [`ROADMAP.md`](./ROADMAP.md)).
